# BREWNS — React + Vite

Premium coffee-house landing page concept with responsive layouts, product cards, a working cart drawer, and editorial sections.

## Run locally

Requirements: Node.js 18.18+ (Node 20 LTS recommended).

```bash
cd brewns
npm install
npm run dev
```

Open the localhost URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The checkout is a visual demo; connect a payment provider and backend before accepting real orders. Product photography and Google Fonts load from external services and require internet access.
